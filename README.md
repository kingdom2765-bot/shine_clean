# 샤인크린

`design/main`의 Stitch 메인 시안을 기준으로 구현한 반응형 웹사이트입니다. 원본 디자인 자료는 유지합니다.

## 실행

Node.js가 설치된 환경에서 프로젝트 폴더를 열고 실행합니다. 화면 실행에는 추가 패키지 설치가 필요 없습니다. 개발 테스트를 실행하려면 먼저 `npm ci`로 개발 의존성을 설치합니다.

```sh
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 수정 후 새로고침하면 반영됩니다.

## 구성

- `pages/index.html`: 메인 화면 본문과 페이지 정보 (수정 원본)
- `components/`: 전 페이지 공통 헤더·푸터·안내창
- `index.html`: 빌드로 조합되는 결과물 (직접 수정하지 않음)
- `design-tokens.css`: 공통 색상·글꼴·크기·여백
- `DESIGN-STANDARD.md`: 신규 페이지에 적용할 디자인 기준
- `styles.css`: 디자인 토큰, 레이아웃, 반응형 스타일
- `app.js`: 모바일 메뉴, 솔루션 안내창, 전화 견적 상담
- `scripts/serve.mjs`: 로컬 미리보기 서버

`npm run build`로 공통 영역을 반영한 HTML을 생성합니다. 미리보기 서버는 HTML 요청 때 자동으로 다시 조합합니다.

## 현재 범위

메인 화면, 병원 정기청소(`/p1-hospital-regular-cleaning.html`), 왜 전문업체인가(`/p2-why-specialist.html`), 작업사례(`/p3-our-work.html`), 업체교체 안내(`/p4-change-guide.html`), 무료견적(`/p5-estimate.html`)을 구현했습니다. P2 비교표는 모바일에서 항목별 카드로 표시됩니다. P1에는 공간별 관리 범위, 서비스 비교표, 견적 요인, 펼쳐 볼 수 있는 FAQ 6개가 있습니다. 전화 상담은 `1661-2816`으로 연결되며, 온라인 견적은 Firebase Cloud Firestore에 저장됩니다.

시안에서 제공된 실적 수치와 문구를 사용했습니다. 공개 운영 전 사업자 정보와 실적, 서비스 표현을 확인해야 합니다. 정식 로고 파일이 없어 텍스트 로고를 사용합니다. Pretendard 웹폰트와 Google Fonts는 인터넷 연결이 필요하며 연결되지 않으면 시스템 글꼴로 표시됩니다.

P4에는 교체 검토 상황 4개, 선정 체크리스트 5개, 견적 비교 기준 6개, 교체 준비 4단계 및 FAQ 4개가 있습니다. 견적 비교는 PC에서 표, 모바일에서 카드로 표시됩니다.

## 작업사례 페이지 (P3)

주소: `/p3-our-work.html`. 가상 의료현장 60개와 시안용 작업 기록 6개를 표시합니다. 실제 실적을 뜻하지 않으며, 페이지와 각 상세 기록에 예시 표시를 유지합니다.

- `data/work.json`: 목록과 사례 콘텐츠 원본. `clients`에는 `id`, 비식별 처리된 `name`, `region`, `specialty`를 입력합니다. 실제 병원 전체 이름을 넣지 않습니다.
- `cases`: `title`, `region`, `specialty`, `area`, `image`, `description`, `tasks`로 사례를 작성합니다. 사진을 `assets/`에 저장한 후 `image` 경로를 변경합니다.
- `work.css`: P3 레이아웃. `work.js`: 12개 단위 목록 페이지 이동·이미지 상세창.
- 변경 후 `npm run build`로 반영합니다. 실제 자료로 전환할 때 예시 문구와 상단 건수도 함께 확인합니다.

현재 작업사례 자료를 업로드하는 관리자 기능은 없습니다. 작업사례는 자료 파일을 편집해 교체하는 구조입니다. 견적 요청은 아래 별도 관리자 화면에서 관리합니다.

## 무료견적 신청 화면 (P5)

주소: `/p5-estimate.html`. `pages/p5-estimate.html`, `estimate.css`, `estimate.js`에서 관리합니다. 기본 정보, 진료 유형, 전용면적, 관리 주기, 기존 업체 교체 상담 여부, 요청사항, 개인정보 동의를 입력하고 확인창에서 내용을 검토한 후 접수합니다.

`firebase-client.js`가 `trading-dashboard-480711` 프로젝트의 Cloud Firestore `estimate_requests`에 저장합니다. 저장 성공을 확인한 후 접수번호를 표시하며, 실패하면 재시도를 안내합니다. 개인정보 보관 기간 안내는 접수 후 90일로 유지하며, 자동 삭제(TTL)는 사용자 요청으로 해제했습니다. 삭제는 관리자가 확인하여 처리합니다. 일반 방문자는 유효한 신청을 새로 등록할 수 있고 기존 신청의 조회·수정·삭제는 지정 관리자만 할 수 있습니다. 이메일·문자 접수 알림 자동 발송은 포함하지 않습니다. 자세한 설정과 확인 방법은 `FIREBASE.md`를 참고합니다.

## 견적 관리자 화면 (P6)

주소: /p6-admin.html. 푸터의 관리자 접속으로 이동합니다. 지정 이메일 계정으로 로그인하여 목록·상세 조회, 상담 메모, 상태 변경, 삭제를 할 수 있습니다. 첫 로그인과 사용 방법은 [ADMIN.md](ADMIN.md)를 참고합니다.
