재계약 시점은 업체를 냉정하게 평가할 수 있는 가장 좋은 기회입니다.

결론부터 말씀드리면, 큰 불만은 없지만 만족스럽지도 않은 상태라면 감으로 결정하기보다 항목별로 점수를 매겨 강남구 한의원 병원청소업체 교체 여부를 판단해 보세요.

## 재계약 평가표 예시

| 항목 | 평가(상·중·하) |
| --- | --- |
| 정해진 일정대로 작업했는가 | |
| 치료실·대기실·화장실 청결 상태가 일정했는가 | |
| 온열기기 주변 등 주의 구역 원칙을 지켰는가 | |
| 요청 사항에 빠르게 대응했는가 | |
| 담당 직원이 안정적으로 유지되었는가 | |
| 관리자 점검과 보고가 있었는가 | |
| 파손·보안 문제가 없었는가 | |
| 비용 대비 만족도 | |

## 판단 기준

- "하"가 두세 개 이상이면 재계약 전에 개선 계획을 요구하고, 받아들일 만하지 않으면 교체를 검토합니다.
- 대부분 "중"이라면 아쉬운 항목을 재계약 조건에 넣어 개선을 약속받는 방법도 있습니다.

## 준비 시점

재계약 통보 기한보다 한두 달 먼저 평가해야 다른 업체와 비교할 시간이 생깁니다.

## 평가 결과를 업체와 공유하기

평가표를 업체에 보여주고 "하" 항목에 대한 개선 계획을 받아 보세요. 계획이 구체적이고 기한이 있다면 재계약 조건에 넣어 관리하면 됩니다. 계획이 막연하다면 다른 업체와 비교해 볼 시점입니다. 이렇게 하면 강남구 한의원 병원청소업체 교체 결정을 감이 아니라 기록으로 할 수 있습니다.

## 놓치기 쉬운 점

- 대치·도곡처럼 지역 환자가 꾸준한 한의원은 업체를 자주 바꾸는 것도 부담이므로, 평가를 근거로 개선을 요청하는 과정이 중요합니다.
- 교체를 결정하기 전에는 [청소업체 비교·선정 기준](/p4-change-guide.html#comparison-criteria)을 함께 확인해 보세요.

원내케어는 교체 상담 시 현재 관리 상태를 함께 점검합니다.

강남구 한의원의 방문 일정과 작업 범위는 [강남구 병원청소 서비스](/area/gangnam.html)에서 확인하고 상담할 수 있습니다.
