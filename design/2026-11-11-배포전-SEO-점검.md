# 2026-11-11 배포 전 SEO 점검

대상: 로컬 소스에서 생성한 배포 폴더 `_site/`. 정식 도메인: https://www.wonnaecare.co.kr/

## 결과

점검 범위에서 배포를 막는 메타데이터·사이트맵 오류는 발견되지 않았습니다. 발견한 중복 메타데이터와 서비스 구조화 데이터의 누락을 보완했습니다. 운영 사이트 배포 및 Google의 실제 색인 상태 확인은 이번 로컬 점검에 포함되지 않습니다.

## 점검 중 보완한 내용

1. 실적 목록 2~10페이지의 검색 제목과 설명을 페이지 번호별로 구분했습니다. canonical은 각 페이지 고유 주소를 유지합니다. Open Graph와 WebPage 구조화 데이터도 변경된 제목·설명을 따라 생성됩니다.
2. 강남구·서초구 페이지에 Service 구조화 데이터를 추가해 송파구·강동구와 같은 기준으로 맞췄습니다.
3. `_site/` 패키징 시 현재 siteUrl 호스트와 일치하는 CNAME을 포함하도록 보완했습니다.
4. SEO.md의 이전 GitHub 주소와 미완료 상태 설명을 현재 설정 및 사용자가 제공한 Search Console 확인 내용에 맞춰 갱신했습니다. 이전 호스트 전용 robots 배포 자료는 보관 자료로 구분했습니다.

## 지역 목록과 사이트맵의 구분

서울 25개 구·경기 31개 시·군 목록은 서비스 제공 범위 페이지의 본문 콘텐츠입니다. 실제 독립 페이지가 있는 강남·서초·송파·강동만 사이트맵에 개별 URL로 포함됩니다. 독립 페이지가 없는 지역에 가상의 URL을 추가하지 않았습니다. PC에서 접힌 목록도 HTML에는 포함되며, 모바일에서는 요청에 따라 숨김 처리합니다.

## 배포 후 확인할 항목

이번 결과는 배포 전 파일 검사입니다. 배포 완료 후 정식 도메인의 `/sitemap.xml`, `/robots.txt`, 신규 페이지 5개가 정상 응답하는지 확인해야 합니다. Google Search Console의 사이트맵 재수집 및 실제 색인 여부는 운영 환경에서 확인해야 하며, 로컬 검사 통과만으로 색인 완료를 의미하지 않습니다.
