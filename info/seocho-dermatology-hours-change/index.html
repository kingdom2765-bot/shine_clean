서초구 피부과 병원 정기청소, 진료 시간이 바뀔 때 다시 짜는 법

게시 2026-11-12

서초동·교대역 일대 피부과는 직장인 환자 수요에 따라 야간진료를 새로 시작하거나 요일별 진료 시간을 조정하는 경우가 있습니다. 진료 시간은 바뀌었는데 청소 일정은 그대로 두면, 청소 직원이 도착했을 때 아직 진료 중이거나 작업 시간이 부족해집니다.

진료 시간 변경 시 확인할 것

  • 작업 시작 시간: 진료 종료 후 몇 분 뒤에 시작할지 다시 정합니다.
  • 건물 출입 시간: 늦어진 작업 시간에 건물 출입이 가능한지 확인합니다.
  • 작업량 변화: 진료 시간이 늘면 공간 사용량도 늘어 작업 시간이 더 필요할 수 있습니다.
  • 비용: 작업 시간대가 바뀌면 할증 조건이 달라지는지 확인합니다.

바꾸는 순서

  • 변경될 진료 시간과 적용일을 업체에 미리 알립니다.
  • 업체가 인력과 작업 시간을 다시 산정합니다.
  • 변경 첫 주에는 작업 결과를 확인하고 조정합니다.
  • 합의된 내용을 계약서나 작업 지침서에 반영합니다.

예약제 피부과라면

종료 시간이 날마다 다르다면 "마지막 예약 종료 후 30분" 같은 기준을 정해 두는 방법도 있습니다.

원내케어는 진료 시간 변경 시 작업 일정과 인력 운영을 다시 협의합니다.
