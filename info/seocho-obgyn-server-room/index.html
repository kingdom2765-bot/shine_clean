서초구 산부인과 병원청소, 서버실·전산실 관리 원칙

게시 2026-11-02

입원실이나 여러 진료실을 운영하는 규모 있는 산부인과는 전자 진료기록 서버, 네트워크 장비, 영상 저장 장비를 별도 공간에 둡니다. 이 공간은 먼지가 쌓이면 장비에 좋지 않지만, 물이나 잘못된 접촉은 더 큰 문제를 일으킬 수 있습니다.

출입 원칙

서버실 출입 여부는 병원이 결정합니다. 출입하지 않는다면 계약서에 제외 공간으로 적어 둡니다. 출입한다면 병원 담당자가 정한 시간에만 들어가고, 출입 기록을 남깁니다.

작업 원칙

  • 물 사용 금지: 물걸레나 분무 세제는 쓰지 않고, 마른 청소만 합니다.
  • 장비 비접촉: 랙, 서버, 케이블, 전원 장치는 만지지 않습니다.
  • 바닥 위주: 장비 주변 바닥 먼지만 제거합니다.
  • 문 관리: 작업 후 문을 반드시 닫고 잠금 상태를 확인합니다.

관리 주기 매일 할 필요는 없고, 주 1회나 월 1회처럼 정해 병원 담당자가 있을 때 작업하는 방식이 안전합니다.

정보 보호 서버실에는 환자 정보가 저장된 장비가 있으므로, 출입하는 직원은 비밀유지 서약 대상에 포함되어야 합니다.

서초구처럼 규모가 다양한 의료기관이 많은 지역에서는 병원마다 전산 공간 구성이 다르니 현장에서 범위를 확인하세요. 원내케어는 출입 제한 구역을 작업 지침에 명시합니다.
