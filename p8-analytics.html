관리자 로그인

지정된 관리자 계정으로 로그인해 주세요.

처음 이용하시면 위 버튼을 눌러 이메일에서 비밀번호를 설정해 주세요.

이메일 인증이 필요합니다

이메일 인증을 완료한 관리자만 통계를 확인할 수 있습니다.

조회 기간과 경로

한국시간 기준 · 상세 조회 최근 90일 · 방문 단위는 현재 탭에서 30분 이내 이어진 활동입니다. 동일인의 다른 방문은 중복될 수 있습니다. 전화 클릭은 실제 통화 완료와 다릅니다. 서로 다른 탭·브라우저의 동일인은 구분할 수 없습니다.

선택한 기간에 수집된 방문 기록이 없습니다.

일별 방문과 전화 클릭

남색: 방문 단위 · 베이지: 전화 클릭 방문. 이전 동일 기간 대비 변화는 요약 카드에서 확인하세요.

유입 경로별 성과

광고비는 입력한 캠페인의 합계입니다. 미입력은 ‘—’로 표시합니다. 기기별 광고비를 분리할 근거가 없어 기기 필터 사용 시 비용 지표를 표시하지 않습니다.

캠페인·콘텐츠 성과

첫 방문 페이지·소재·키워드 보기

키워드는 태그로 전달한 영문 관리 코드만 표시합니다. 자연검색 원문 검색어는 수집하지 않습니다.

전화 버튼 위치

모든 전화 버튼의 클릭을 집계합니다. 같은 방문 단위에서 여러 번 누르면 전화 클릭 방문은 1회, 클릭 횟수는 누른 횟수로 표시합니다.

과도한 조회·의심 활동

현재 방문 안에서 과도한 조회와 반복 동작을 검토합니다. 다른 방문을 동일인으로 연결하지 않으므로 하루 재방문 횟수·반복 광고 유입으로 사람을 추적하지 않습니다. 제외는 해당 방문 단위에 적용됩니다. 기존 자료는 이전 집계 기준을 따릅니다.

광고·홍보 링크 만들기

캠페인·소재 코드는 영문 소문자·숫자·하이픈을 사용하세요. 연락처·이름 등 개인정보는 입력하지 마세요. 네이버 블로그와 파워컨텐츠, 지도 프로필 링크를 각각 구분해서 사용하세요.

광고비·노출·클릭 입력

같은 날짜·채널·캠페인은 최신 입력으로 대체됩니다. 금액은 모든 채널에서 같은 세금 포함 기준으로 입력하세요.

등록한 광고비 확인

실제 전화 상담 기록

통화가 확인된 상담을 기록하세요. 출처는 고객 확인 등 근거가 있을 때 선택합니다. 전화 클릭과 자동으로 동일인 처리하지 않습니다. 이름·전화번호는 여기에 입력하지 마세요.

장기 추이

식별정보 없는 일별 집계를 최대 24개월 보관합니다. 당일은 상세 통계를 이용하세요. 여러 날짜의 방문 합은 방문 단위의 합계이며 실제 사람 수가 아닙니다. 기존 장기 자료에는 이전 브라우저 집계 방식이 포함될 수 있습니다. 90일이 지난 자료에는 현재 제외 설정을 소급 적용할 수 없습니다.

측정·연동 상태

방문자에게 확인창을 띄우지 않습니다. 현재 탭의 짧은 방문 정보만 사용하며 신규·재방문자 구분과 장기간 동일인 추적은 하지 않습니다. 브라우저 추적 거부 설정·차단 등으로 누락될 수 있습니다. 관리자 페이지와 로컬 개발 접속은 수집하지 않습니다. 실제 통화 서비스는 서명된 웹훅 연결이 필요하고, 광고 플랫폼 API 계정은 별도 연결이 필요합니다.

견적 성과는 접수일 기준이며 상담 상태 변경에 따라 유효 문의·계약 건수가 갱신됩니다. 유효 문의는 ‘상담 중·견적 전달·계약 완료’ 상태입니다. 견적 경로는 현재 방문 안의 마지막 비직접 유입을 사용합니다. 전화 클릭과 전화 상담·견적은 별도 행동이므로 합계를 전체 고객 수로 해석하지 마세요.
